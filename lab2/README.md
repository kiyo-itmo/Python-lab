## Отчёт по лабораторной работе №2

**Вариант:** 4  
**Тема:** Обработка данных в форматах CSV и XML средствами Python  
**Используемые файлы:** `books-en.csv`, `currency.xml`  
**Программные средства:** Python 3, стандартные модули `csv` и `xml.dom.minidom`.

### 1. Цель работы

Научиться читать и обрабатывать файлы CSV и XML с помощью Python; применять условия, циклы и функции, использовать списки, множества и словари, сортировать данные и записывать результаты в текстовый файл.

### 2. Постановка задачи (вариант 4)

Для файла `books-en.csv` требуется:

1. Подсчитать число книг, названия которых длиннее 30 символов.
2. Реализовать поиск книг по автору с ограничением цены **до 200 рублей** (в программе используется `price <= 200`).
3. Сформировать 20 библиографических ссылок в формате `<автор>. <название> - <год>` и сохранить их в отдельном пронумерованном текстовом файле.

Для файла `currency.xml` требуется создать словарь вида `NumCode → CharCode`.

**Дополнительные задания:** вывести издательства без повторений и определить 20 самых популярных книг. Для оценки популярности выбран показатель `Downloads` (количество скачиваний). Это принятое при реализации решение, поскольку в условии критерий популярности не уточняется.

### 3. Ход работы

#### 3.1. Чтение CSV-файла

Данные считываются с помощью `csv.reader()` с разделителем `;` и кодировкой `cp1251`. Первая строка с названиями столбцов пропускается функцией `next(reader)`. Оставшиеся записи сохраняются в список `books`.

Основные поля: `row[1]` — название, `row[2]` — автор, `row[3]` — год, `row[4]` — издательство, `row[5]` — скачивания, `row[6]` — цена.

#### 3.2. Подсчёт названий длиннее 30 символов

Функция `count_titles(books)` перебирает записи и проверяет условие `len(row[1]) > 30`. Если условие выполнено, счётчик увеличивается на единицу.

#### 3.3. Поиск книг по автору с ограничением цены

Функция `search_by_author(books)` получает запрос через `input()`. Методы `strip()` и `lower()` позволяют убрать лишние пробелы и выполнять поиск без учёта регистра. Для каждой книги проверяется наличие запроса в имени автора и условие `price <= 200`.

В исходных данных цены могут иметь десятичную запятую. Перед числовым сравнением применяется `float(row[6].replace(",", "."))`. При некорректном числовом значении предусмотрен пропуск записи с помощью `try/except ValueError`. Программа выводит подходящие книги и их количество либо сообщение об отсутствии результатов.

#### 3.4. Формирование библиографических ссылок

Функция `write_references(books)` составляет строки вида `Автор. Название - Год` с помощью f-строк. Перед записью проверяется, что год состоит из четырёх цифр. Пронумерованные строки записываются в `references.txt` в кодировке UTF-8. После записи 20 ссылок цикл завершается оператором `break`. Если корректных записей недостаточно, программа выводит предупреждение.

#### 3.5. Обработка XML-файла

Функция `show_currencies()` использует `minidom.parse("currency.xml")`, получает элементы `Valute` и извлекает из каждого `NumCode` и `CharCode` с помощью `getElementsByTagName()`. Результаты сохраняются в словарь `currencies[num_code] = char_code`. Числовые коды остаются строками, чтобы сохранить ведущие нули, например `"036"`. Для проверки применяется `len(currencies)` и поиск по ключу `"840"`.

#### 3.6. Дополнительное задание: уникальные издательства

Функция `unique_publishers(books)` создаёт множество `set()`, добавляет значения `row[4]` методом `add()` и выводит список издательств в отсортированном порядке через `sorted()`.

#### 3.7. Дополнительное задание: 20 популярных книг

Функция `top_20_books(books)` формирует записи `[название, автор, количество скачиваний]`. Поле скачиваний преобразуется в `int`. Список сортируется по убыванию с помощью `sorted(..., key=lambda book: book[2], reverse=True)`. Затем выбираются первые 20 записей срезом `[:20]` и выводятся с нумерацией через `enumerate(start=1)`.

При равном количестве скачиваний сохраняется исходный относительный порядок записей; поэтому выбранные 20 книг являются одной из возможных выборок из группы самых скачиваемых.
