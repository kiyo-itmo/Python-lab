# Лабораторная работа №3

## Тема работы
Разработка генератора ключей с графическим интерфейсом на Python.

## Цель работы
Изучить основы создания графического интерфейса с помощью библиотеки `tkinter`, научиться работать со случайными символами и реализовать алгоритм генерации ключей по заданным правилам.

## Задание

Разработать программу-генератор ключей для абстрактного программного обеспечения с использованием библиотеки `tkinter`.

Программа должна содержать:
- Фоновое изображение, связанное с выбранной игрой.
- Поле для отображения сгенерированного ключа.
- Кнопку для генерации ключа.
- Алгоритм генерации ключа согласно варианту.

## Вариант 4

**Формат ключа:** `XXXX-XXXX-XXXX`

Ключ состоит из трёх блоков по четыре символа. Каждый блок может содержать латинские заглавные буквы `A-Z` и цифры `0-9`.

Каждому символу назначается весовой коэффициент. Сумма весовых коэффициентов символов каждого блока должна находиться в заданном интервале.

В программе используются следующие правила:
- Буквы имеют веса от 1 до 26: A = 1, B = 2, ..., Z = 26.
- Цифры имеют веса от 0 до 9.
- Выбранный интервал суммы весов: от 30 до 35 включительно.

## Описание программы

Программа состоит из графического интерфейса и генератора ключей.

Для создания интерфейса используется библиотека `tkinter`. На фоне отображается изображение игры. Пользователь нажимает кнопку `GENERATE KEY`, после чего программа создаёт ключ и выводит его в поле `Entry`.

### Основные функции

**1. `get_weight(char)`**

Определяет весовой коэффициент одного символа. Для букв используется функция `ord()`, для цифр — преобразование `int()`.

**2. `calculate_weight(block)`**

Вычисляет сумму весовых коэффициентов всех символов одного блока с помощью цикла `for`.

**3. `generate_block()`**

Создаёт случайный блок из четырёх символов с помощью `random.choice()`.

Цикл `while True` повторяет генерацию, пока сумма весов блока не попадёт в интервал от 30 до 35.

**4. `generate_key()`**

Вызывает функцию `generate_block()` три раза и объединяет полученные блоки через дефис.

**5. `show_key()`**

Удаляет предыдущий ключ из поля `Entry` и отображает новый.

## Алгоритм работы

1. Пользователь запускает программу.
2. Открывается окно с фоновым изображением и кнопкой генерации.
3. При нажатии кнопки программа случайно выбирает четыре символа.
4. Вычисляется сумма весовых коэффициентов выбранных символов.
5. Если сумма не входит в интервал 30–35, блок создаётся заново.
6. После получения трёх подходящих блоков они объединяются в один ключ.
7. Готовый ключ отображается в графическом интерфейсе.

## Дополнительное задание

В программу добавлены фоновая музыка и анимация.

### Фоновая музыка

Для воспроизведения музыки используется библиотека `pygame`.

Музыка загружается из файла `music.mp3`, воспроизводится с громкостью 30% и автоматически повторяется.

При закрытии окна воспроизведение останавливается.

### Анимация

Для анимации используется метод `after()` библиотеки `tkinter`.

Заголовок программы меняет цвет с белого на жёлтый и обратно каждые 500 миллисекунд.

## Пример генерации ключа

Пример из задания:

```text
YABD-NBCO-DGIK
```

Проверка суммы весов:

| Блок | Вычисление | Сумма |
|---|---|---|
| YABD | 25 + 1 + 2 + 4 | 32 |
| NBCO | 14 + 2 + 3 + 15 | 34 |
| DGIK | 4 + 7 + 9 + 11 | 31 |

Все три блока соответствуют условию: сумма весовых коэффициентов находится в интервале от 30 до 35.

Фактические ключи создаются случайным образом и могут отличаться от приведённого примера.
