# Лабораторная работа №1 — Базовые скрипты на Python

Данная лабораторная работа посвящена изучению базового синтаксиса Python, работе с ANSI-последовательностями для работы с цветом в терминале, созданию простых анимаций, генерации процедурных паттернов и обработке текстовых данных.

## Содержимое репозитория

В папке находятся следующие файлы:
*   `task1_flag.py` — Скрипт, выводящий флаг Монако/Индонезии в консоль.
*   `task2_pattern.py` — Процедурная генерация повторяющегося геометрического узора.
*   `task3_animation.py` — Консольная анимация мигающей новогодней елки.
*   `task4_diagram.py` — Скрипт для анализа числовых последовательностей и построения цветной диаграммы.
*   `sequence.txt` — Файл с исходными данными для Задачи №4.

---

## Описание задач и их запуск

### Задача 1: Рисование флага
*   **Файл:** `task1_flag.py`
*   **Описание:** Скрипт использует ANSI escape-коды для изменения фона терминала (`CSI + "41m"` для красного и `CSI + "107m"` для белого), формируя двухцветный флаг заданной высоты и ширины.
*   **Запуск:**
    ```bash
    python task1_flag.py
    ```

### Задача 2: Рисование узора
*   **Файл:** `task2_pattern.py`
*   **Описание:** Процедурно генерирует повторяющийся симметричный узор в виде буквы "d" или катушки. Принимает параметры ширины и количества повторений по горизонтали. Автоматически корректирует четную ширину до нечетной для сохранения идеальной симметрии центрального блока.
*   **Запуск:**
    ```bash
    python task2_pattern.py
    ```

### Задача 3: Анимация (Ёлочка)
*   **Файл:** `task3_animation.py`
*   **Описание:** Создает эффект мерцания елки за счет циклического переключения между тремя разными оттенками зеленого цвета (`256-color palette` в ANSI). Перед каждым новым кадром терминал очищается командой `os.system("cls" или "clear")`, а задержка реализуется через `time.sleep(0.5)`.
*   **Запуск:**
    ```bash
    python task3_animation.py
    ```

### Задача 4: Статистическая диаграмма
*   **Файл:** `task4_diagram.py`
*   **Описание:** Читает 250 чисел из файла `sequence.txt`, делит их на две группы по 125 элементов. Скрипт вычисляет среднее абсолютное значение (по модулю `abs(x)`) для каждой группы, определяет их процентное соотношение и строит горизонтальную визуальную гистограмму (синяя полоса для первой группы, красная для второй).
*   **Запуск:**
    ```bash
    python task4_diagram.py
    ```
